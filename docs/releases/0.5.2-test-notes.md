# 0.5.2 test notes

After installing this release on the A14:

```sh
sudo systemctl restart asus-zenbook-a14-ec.service
modinfo hid_asus_ec | grep '^depends:'
lsmod | grep -E '^(hid_asus_ec|asus_zenbook_a14_ec)'
```

Fn+F should cycle:

`Whisper -> Quiet -> Normal -> Turbo -> Full Speed -> Whisper`

For continuous IR, first smoke-test the hardware Torch path independently of Aegis:

```sh
./scripts/a14-ir-torch-smoke.sh 35 2
```

Then apply the source patch to Aegis Hello 0.8.3 and reinstall Aegis.
